# Prompts

Prompts from AI Experts that you can paste straight into ChatGPT, Claude, Claude Code or Codex.
Each file opens with a short note on what it does and what you need. Copy everything below the
line into your assistant.

| Prompt | What it does |
|---|---|
| [breach-check.md](breach-check.md) | Finds the data breaches and security flaws reported in the last 30 days, checks your inbox for accounts you hold with those companies, and tells you which passwords to change. Read-only, and it never asks for a password. |
| [herdr-cloud-box.md](herdr-cloud-box.md) | Has a coding agent build you an always-on cloud box for your agents: a DigitalOcean server running herdr, Claude Code and Codex behind Cloudflare Tunnel and Access, reachable from a browser tab or your phone. |

Read a prompt before you run it. Both ask before they change anything, and the cloud box one
shows you the price before it spends money.
